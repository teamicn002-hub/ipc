# คู่มือนำเว็บไซต์ IPC ขึ้นออนไลน์ (ฟรี) และแก้ไขเอง

## ไฟล์ในชุดนี้
- `index.html` : หน้าเว็บทั้งหมด (ส่วนที่แก้ไขได้อยู่ด้านบนสุดของไฟล์)
- `assets/` : โลโก้ (`logo.png`), ภาพพื้นหลังหน้าแรก (`hero-bg.jpg` สำหรับคอมพิวเตอร์ และ `hero-banner.jpg` สำหรับมือถือ), รูปโรงพยาบาล (`hospital-statue.jpg`) ไอคอน (`icons.js`) และฟอนต์ PK Uttaradit (`fonts/`, เวอร์ชันฟรีสำหรับงานที่ไม่ใช่เชิงพาณิชย์ ดูไฟล์ License ที่แนบไว้) **ต้องอัปโหลดทั้งโฟลเดอร์นี้ด้วย** ถ้าจะเปลี่ยนรูป ให้ใช้ชื่อไฟล์เดิม
- `docs/` : โฟลเดอร์สำหรับใส่ไฟล์ PDF (สร้างเพิ่มเองได้)

---

## ขั้นที่ 1: นำเว็บขึ้นออนไลน์ฟรีด้วย GitHub Pages
ได้ที่อยู่เว็บฟรีแบบ `https://ชื่อผู้ใช้.github.io/ipc` และแก้ไขผ่านหน้าเว็บได้เลย ไม่ต้องลงโปรแกรม

1. สมัครบัญชีที่ https://github.com (ฟรี) ชื่อผู้ใช้จะกลายเป็นส่วนหนึ่งของที่อยู่เว็บ เช่น `ipc-sirikit`
2. กดปุ่ม **+** มุมขวาบน แล้วเลือก **New repository**
   - Repository name: `ipc` (หรือชื่ออื่น)
   - เลือก **Public** แล้วกด **Create repository**
3. กดลิงก์ **uploading an existing file** แล้วลากไฟล์ `index.html` และโฟลเดอร์ `assets` ลงไปพร้อมกัน จากนั้นกด **Commit changes**
4. ไปที่ **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)** แล้วกด **Save**
5. รอ 1–2 นาที เว็บจะออนไลน์ที่ `https://ชื่อผู้ใช้.github.io/ipc`

> ถ้าต้องการที่อยู่สั้นกว่านี้ ให้ตั้งชื่อ repository เป็น `ชื่อผู้ใช้.github.io` แล้วเว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io`

---

## ขั้นที่ 2: ใส่โปสเตอร์ความรู้ / เอกสาร / แบบฝึกหัด

**วิธี ก (แนะนำ): เก็บไฟล์ใน Google Drive**
1. อัปโหลดไฟล์ขึ้น Google Drive
2. คลิกขวาที่ไฟล์ → **แชร์** → ตั้งค่าเป็น **ทุกคนที่มีลิงก์** (ผู้ดู) → **คัดลอกลิงก์**
3. นำลิงก์ไปใส่ในรายการ `POSTERS` (ส่วน "สื่อความรู้") ใน `index.html` (ดูขั้นที่ 4)

**วิธี ข: เก็บไฟล์ไว้กับเว็บ** (เหมาะกับไฟล์ขนาดไม่เกิน 25 MB)
1. ใน GitHub กด **Add file → Upload files** แล้วพิมพ์ชื่อโฟลเดอร์ `docs/` นำหน้า หรือสร้างโฟลเดอร์ docs ก่อน แล้วอัปโหลดไฟล์ลงไป
2. ใส่ลิงก์ในรายการเป็น `"docs/ชื่อไฟล์.pdf"`
3. ตั้งชื่อไฟล์เป็นภาษาอังกฤษ ไม่มีช่องว่าง เช่น `hand-hygiene.pdf` จะใช้งานได้แน่นอนกว่า

---

**ใส่รูปกิจกรรม:** อัปโหลดรูปไว้ในโฟลเดอร์ `assets` แล้วใส่ชื่อไฟล์ในรายการ `ACTIVITIES` เช่น `image: "assets/act1.jpg"`

---

## ขั้นที่ 3: ใส่คลิปสื่อการสอน
อย่าอัปโหลดไฟล์วิดีโอขึ้นเว็บโดยตรง เพราะไฟล์ใหญ่และเปิดช้า ให้ทำดังนี้แทน
1. อัปโหลดคลิปขึ้น YouTube จะตั้งเป็น **ไม่เป็นสาธารณะ (Unlisted)** ก็ได้ คนทั่วไปจะค้นหาไม่เจอ แต่เล่นในเว็บได้
2. คัดลอกลิงก์คลิป เช่น `https://www.youtube.com/watch?v=abc123XYZ00`
3. นำลิงก์ไปใส่ในรายการ `VIDEOS` (ดูขั้นที่ 4)

## ขั้นที่ 4: แก้ไขเนื้อหาในเว็บ
1. ใน GitHub คลิกไฟล์ `index.html` แล้วกดรูป **ดินสอ ✏️** (Edit)
2. แก้เฉพาะส่วนด้านบนที่มีหัวข้อ **"ส่วนที่แก้ไขได้เอง"**

**เพิ่ม/เปลี่ยนสไลด์หน้าแรก (รายการ `SLIDES`):** สไลด์เลื่อนเองทุก 5 วินาที กดลูกศร จุด หรือปัดนิ้วบนมือถือเพื่อเลื่อนเองได้ ปุ่มกลมมุมขวาล่างใช้หยุด/เล่น
1. อัปโหลดรูปไว้ในโฟลเดอร์ `assets` (แนะนำรูปแนวนอน)
2. เพิ่มบรรทัดในรายการ `SLIDES`
```js
{ image: "assets/slide5.jpg", tag: "ข่าวสาร", title: "หัวข้อที่จะแสดงบนสไลด์", link: "#posters" },
```
- ถ้ารูปมีข้อความอยู่แล้ว ให้เว้น `tag` และ `title` เป็น `""`
- ถ้ารูปถูกตัดผิดจุด ใส่ `pos` เพิ่ม เช่น `pos: "30% center"` (เลื่อนไปทางซ้าย) หรือ `pos: "right center"`

**กิจกรรมและโครงการ (รายการ `ACTIVITIES`):** เรียงตามวันที่ล่าสุดให้อัตโนมัติ กรองได้ตามประเภท
```js
{ title: "ชื่อกิจกรรม/โครงการ", type: "กิจกรรม", date: "2026-10-19", image: "assets/act1.jpg", icon: "sparkles", link: "ลิงก์อัลบั้มรูป" },
```
- `type` ใช้ `"กิจกรรม"` หรือ `"โครงการ"`

**ประกาศ (รายการ `ANNOUNCEMENTS`):** เรียงตามวันที่ล่าสุดให้อัตโนมัติ
```js
{ title: "ชื่อประกาศ", date: "2026-10-19", isNew: true, link: "ลิงก์ไฟล์ประกาศ" },
```

**เพิ่มโปสเตอร์/เอกสาร/แบบฝึกหัด (รายการ `POSTERS` (ส่วน "สื่อความรู้")):** คัดลอกบรรทัดเดิม 1 บรรทัด วางต่อ แล้วเปลี่ยนข้อความ
```js
{ title: "ชื่อโปสเตอร์", category: "handhygiene", type: "IMG", date: "2026-10-19", image: "assets/poster1.jpg", link: "ลิงก์ Google Drive" },
{ title: "ชื่อแบบทดสอบ", category: "quiz", type: "QUIZ", date: "2026-10-19", image: "", link: "ลิงก์ Google Form" },
```

**เพิ่มคลิป:**
```js
{ title: "ชื่อคลิป", category: "handhygiene", youtube: "https://www.youtube.com/watch?v=xxxxxxxxxxx" },
```

**หมวดหมู่ (category) ที่ใช้ได้**

| ค่า | ความหมาย |
|---|---|
| `handhygiene` | การล้างมือ |
| `sp` | แนวทาง (SP.) — Standard Precautions |
| `quiz` | แบบฝึกหัด |

**ประเภท (type):** `IMG` (โปสเตอร์รูปภาพ), `PDF`, `PPT`, `QUIZ` (ลิงก์แบบทดสอบ เช่น Google Form)
**รูปตัวอย่าง (image):** ใส่รูปโปสเตอร์ไว้ในโฟลเดอร์ `assets` แล้วใส่ชื่อไฟล์ เช่น `"assets/poster1.jpg"` (เว้นว่าง `""` ได้)
**วันที่ (date):** รูปแบบ ปี ค.ศ.-เดือน-วัน เช่น `2026-10-19` (เว็บจะแสดงเป็น พ.ศ. ให้อัตโนมัติ)

3. กด **Commit changes** แล้วรอประมาณ 1 นาที เว็บจะอัปเดต (ถ้ายังไม่เปลี่ยน ให้กดรีเฟรชหน้าเว็บ)

> **ข้อควรระวัง:** ต้องมีเครื่องหมาย `"` ครอบข้อความ และมีจุลภาค `,` ท้ายทุกบรรทัด ถ้าเว็บหายหรือว่างเปล่า มักเกิดจากลืมเครื่องหมายเหล่านี้ ให้กลับไปตรวจบรรทัดที่เพิ่งแก้

## ขั้นที่ 5 (ถ้าต้องการภายหลัง): ใช้ชื่อเว็บของตัวเอง
- **ฟรี:** ขอให้ฝ่าย IT ของโรงพยาบาลสร้าง subdomain ให้ เช่น `ipc.ชื่อโรงพยาบาล.go.th` แล้วชี้มาที่ GitHub Pages
- **เสียเงินประมาณ 400–600 บาท/ปี:** ซื้อโดเมน `.com` แล้วไปที่ **Settings → Pages → Custom domain** เพื่อใส่ชื่อโดเมน
